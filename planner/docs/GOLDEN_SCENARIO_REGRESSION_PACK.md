# Sprint 284 — Golden-scenario regression pack

The Sprint 284 golden pack snapshots selected yearly outputs and summary values
for three deterministic retirement-planning cases: the balanced pension-first
case, an ISA-first withdrawal case, and a higher-inflation case with the State
Pension triple-lock disabled and ISA inflation-linking enabled.

The reviewed fixture is `tests/golden/sprint284_scenarios.json`. Tests compare
numeric outputs with a tolerance of 0.011 (fixtures are rounded to two decimal
places). The fixture is never regenerated by the test suite. A deliberate
financial-output change must be investigated, reviewed against the assumptions
and intended policy, and accompanied by an explicit fixture update in the same
change. Do not update golden values merely to make a failing test pass.

The pack complements, rather than replaces, `tests/golden/baseline.json` and
existing tax, withdrawal, end-to-end, and deterministic/Monte Carlo integration
tests. It is a regression contract for the current implementation, not financial
advice, a claim that a strategy is optimal, or validation of every possible
assumption combination.

Run it with:

```bash
python -m pytest -q tests/test_sprint284_golden_scenario_regression_pack.py
```
